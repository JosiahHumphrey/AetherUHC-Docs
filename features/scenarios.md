# Scenarios

AetherUHC comes with **80+ fully implemented, highly configurable scenarios** out of the box. Scenarios modify the base rules of Ultra Hardcore to create unique, varied, and exciting gameplay experiences.

## Enabling & Disabling Scenarios

Scenarios can be toggled via the in-game GUI or commands:
- **Command:** `/scenarios` (Opens the Scenario Manager menu)
- **Host Permission required:** `aetheruhc.host`
